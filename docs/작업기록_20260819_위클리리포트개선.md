# 위클리리포트 기능 및 UI 개선 작업 기록

## 작업 일자

- 2026-08-19

## 주요 변경 사항

### 위클리리포트 관리 분리

- 위클리리포트 생성 기능을 일반 목록 화면에서 설정의 `위클리리포트 관리` 화면으로 이동했다.
- 관리자와 운영자만 리포트를 생성할 수 있도록 기존 서버 권한 검증을 유지했다.
- 일반 위클리리포트 화면은 검색, 목록, 상세 조회, 출력 기능 중심으로 정리했다.

### 생성 및 중복 처리

- 연도·월·주차를 기준으로 실적 기간과 계획 기간을 계산한다.
- 이미 생성된 주차는 다시 생성하지 않고 사용자에게 기존 리포트를 확인하도록 안내한다.
- PM 확인이 완료된 주차는 확인 취소 전까지 생성·수정을 제한한다.
- 리포트명은 `PMO CONTROL` 프로젝트에서도 `PMO 위클리 리포트`로 표시되도록 정규화했다.

### 목록 및 상세 기능

- 리포트 목록에 검색과 서버 페이지네이션을 적용했다.
- 전체 페이지가 1개인 경우에도 이전·현재 페이지·다음 상태를 표시한다.
- 업무그룹별 실적, 계획, 이슈 및 요청사항을 상세 화면에서 입력·조회할 수 있도록 구성했다.
- 담당 업무그룹 사용자와 관리자·운영자의 수정 권한을 서버에서 검증한다.
- 관리자가 PM 확인 완료와 확인 취소 상태를 전환할 수 있도록 했다.

### UI 안정성 개선

- 상세 및 출력 화면에서 공백 없는 긴 문자열도 셀 안에서 줄바꿈되도록 처리했다.
- 출력 테이블이 문서 폭을 넘어가지 않도록 고정 레이아웃을 적용했다.
- 그룹 관리의 코드·명칭·색상·순서·활성·저장 항목이 데스크톱에서 한 줄에 표시되도록 그리드 열을 수정했다.
- 화면 제목 아래 설명 문구는 요청이 있을 때만 추가하는 UI 작성 원칙을 작업 메모에 반영했다.
