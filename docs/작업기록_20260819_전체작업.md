# PMOTOOLS 통합 작업 기록 (2026-08-19)

> 대상 저장소: `mohenz/pmotools`
> 운영 서비스: `https://pmotools.vercel.app`
> 기준 브랜치: `main`

## 1. 프로젝트 통합 모니터링

- 프로젝트 통합 모니터링용 관리업무항목 목록, 등록, 상세, 대시보드 화면을 추가했다.
- 관리업무항목의 수정, 보관, 연관 항목 연결, 검색 API를 구현했다.
- 관리업무 상태 표기를 화면 목적에 맞게 간소화했다.
- `PM`, `PMO` 직무 사용자만 이슈관리와 프로젝트 통합 모니터링 메뉴 및 경로에 접근할 수 있도록 서버·화면 권한을 적용했다.
- 관리업무 데이터 모델과 마이그레이션 `20260819120000_add_management_tasks`를 추가했다.

## 2. 위클리리포트 개선

- 위클리리포트 생성 기능을 설정의 관리 화면으로 분리했다.
- 관리 화면에서 생성된 위클리리포트 목록을 조회하고 삭제할 수 있도록 했다.
- 삭제 시 해당 주차에 주간실적이나 인력변동 데이터가 없으면 `weeks` 데이터도 함께 삭제하고, 관련 데이터가 있으면 위클리리포트만 삭제하도록 개선했다.
- 위클리리포트 생성 시 활성 상태인 업무그룹만 포함하도록 했다.
- 리포트 중복 생성 방지, PM 확인 완료·취소, 업무그룹별 작성 권한을 적용했다.
- 목록 검색과 서버 페이지네이션, 상세 입력, 출력 화면을 개선했다.
- 긴 문자열의 셀 넘침과 출력 폭 문제를 수정했다.
- 동적 API 경로 이름을 통일해 배포 시 원복되거나 라우트가 충돌하는 문제를 해소했다.

상세 내용은 `docs/작업기록_20260819_위클리리포트개선.md`에 별도로 기록되어 있다.

## 3. 사용자 관리 및 직무 기반 권한

- 사용자 정보에 직무 필드를 추가하고 화면 명칭을 `직책`에서 `직무`로 변경했다.
- 사용자 관리 목록에 요구사항관리와 같은 방식의 서버 페이지네이션을 적용했다.
- 페이지 크기는 20건, 40건, 80건, 100건, 전체를 지원한다.
- 사용자 검색 시 아이디, 이름, 직무를 기준으로 조회할 수 있도록 했다.
- 사이드바의 사용자 이름을 클릭하면 `나의 정보` 화면으로 이동하도록 프로필 링크를 추가했다.
- 사용자 정보 및 리포트명 표기를 정리했다.
- 직무 필드 마이그레이션 `20260819053000_add_user_job_title`을 추가했다.

## 4. 캘린더 개선

- 주간·일간 시간표 일정의 높이를 실제 시작·종료 시간에 맞게 계산하도록 개선했다.
- 15:00~17:00 일정이 15:30까지만 보이던 표시 오류를 수정했다.
- 일정을 등록한 사용자만 수정, 수정 취소, 삭제할 수 있도록 서버 권한 검증을 추가했다.
- 등록자가 아닌 사용자는 일정 모달을 조회 전용으로 사용할 수 있도록 했다.
- 일정 보기 모달의 불필요한 안내 문구를 제거했다.
- 일정 담당자로 지정된 내부 사용자를 일정 초청 대상자로 처리하도록 했다.
- 초청받은 사용자가 로그인하면 미확인 일정 목록을 모달로 표시하고 쪽지함에도 초청 내용을 남기도록 했다.
- 일정 초청 조회·확인 API와 미확인 건수 갱신을 구현했다.
- 일정 초청용 메시지 유형과 캘린더 연결 필드를 추가하는 마이그레이션 `20260819152000_add_calendar_invitations`를 작성했다.

## 5. 쪽지함 개선

- 새 쪽지 작성 화면에서 조회 비밀번호 입력 항목을 제거했다.
- 쪽지를 펼치면 별도 비밀번호 확인 없이 즉시 내용을 조회하도록 변경했다.
- 새 일반 쪽지는 `MESSAGE_ENCRYPTION_KEY`를 우선 사용하고, 없으면 `AUTH_SECRET`을 사용해 서버에서 암호화·복호화한다.
- 일정 초청 쪽지는 일정명, 기간, 장소, 초청자와 일정 바로가기를 표시한다.
- 기존 사용자 지정 비밀번호로 암호화된 쪽지는 원래 비밀번호 없이 변환할 수 없으므로 자동 열람 불가 안내를 표시한다.

## 6. HTML 매뉴얼 및 화면 구성

- 사이트 내 `매뉴얼` 메뉴와 목록·상세 화면을 추가했다.
- 위클리리포트, 공지사항, 캘린더, 회의실 HTML 매뉴얼을 작성해 연결했다.
- 매뉴얼 첫 화면을 카드형에서 목록형으로 변경했다.
- 각 목록 행의 제목과 설명을 한 줄로 배치해 불필요한 세로 여백을 줄였다.
- 메인 화면의 기본 진입점을 공지사항으로 변경했다.
