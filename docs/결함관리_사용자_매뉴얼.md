# 결함관리 사용자 매뉴얼

테스트 > 결함관리 메뉴에서 사용합니다. 하위 프로젝트를 선택한 상태에서만 동작합니다.

## 1. 누가 무엇을 볼 수 있나
- 관리자·슈퍼관리자·운영자·PMO: 프로젝트 전체 결함
- 그 외: 내가 등록했거나 내가 조치자인 결함, 내가 리더인 업무단위의 결함, 내가 QC·PL인 케이스의 결함

## 2. 결함 등록
1. **결함 등록**에서 제목(5자 이상), 테스트 단계, 심각도를 입력합니다.
2. 화면경로는 필수가 아닙니다. 직접 입력하거나, 화면 목록에서 고르거나, 화면 URL을 입력하면 맞는 화면경로를 제안합니다.
3. 단위테스트 케이스는 검색해서 연결할 수 있습니다. 연결하지 않으면 독립 결함입니다.
4. 증적은 결함당 3개, 파일당 20MB까지 올리며, 화면에서 Ctrl+V로 이미지를 붙여넣을 수 있습니다.
5. 결함번호는 `DF-yymmdd-5001`부터 자동으로 붙습니다(단위테스트 결함 번호와 겹치지 않음).

조치자는 연결된 WBS Task의 작업자가 기본값입니다. Task가 없으면 미배정이며, **미배정 결함** 화면에서 QC·PL·운영자·업무그룹리더·PMO·관리자가 지정합니다.

## 3. 상세·조치
- 등록자: 제목·재현 단계·화면 정보·심각도·우선순위를 고칠 수 있습니다.
- 조치자: 상태, 결함식별, 조치 내용, 조치 예정·시작·종료일을 입력합니다.
- 모든 변경은 이력에 남고, 이력은 고치거나 지울 수 없습니다. 결함 삭제는 관리자만 하며 목록에서만 사라집니다.
- 다른 사람이 먼저 고쳤다면 "다시 확인" 안내가 나옵니다. 화면을 새로 고친 뒤 다시 저장하세요.

## 4. 통계보기
- **테스트별 현황**: 단계·Task·업무단위별 미조치/조치완료/종결 건수, 조치완료율, 미조치 중대 결함, 미배정, 조치 예정일 초과. 단위테스트 결함도 읽기 전용으로 합산합니다.
- **조치자 현황**: 담당자별 건수(미배정 행 포함).
- **조치 재확인**: 완료·종결인데 결함식별과 조치 내용이 모두 빈 결함.
- WBS 진척·실적일은 바뀌지 않습니다.

## 5. 설정 (변경은 운영자·PMO·관리자)
- **미조치 중대 결함 기준**: 체크한 심각도의 미조치 결함을 "미조치 중대 결함"으로 셉니다. 상태가 미조치/조치완료/종결 중 무엇으로 집계되는지는 기본값(접수·조치중·재오픈=미조치, 조치완료·반영대기=조치완료, 종결)을 씁니다.
- **대상 도메인**: 위젯·확장 프로그램이 동작할 테스트 대상 사이트(초기: cinetube `http://localhost:8080`, secret album `http://localhost:8090`).
- **화면 목록**: 단건 등록, 엑셀 일괄 등록(양식 내려받기 → 업로드·검증 미리보기 → 오류가 없을 때 반영), 현재 목록 내려받기. 오류가 하나라도 있으면 아무것도 반영되지 않습니다.

- **테스트 단계 등록·잠금**(슈퍼관리자): 설정 > 프로젝트 관리 > 프로젝트 정보 화면의 "테스트 단계"에서 단계를 등록하고, 위·아래 버튼으로 순서를 바꾸고 잠금으로 체크한 뒤 "저장"을 누르면 순서대로 선택지·필터·통계 단계 표가 나오며, 잠금한 단계는 그 단계가 결함 등록·상세 선택지, 목록 필터, 통계 필터에서 보이지 않습니다. 이미 등록된 결함은 그대로 남고, 모든 단계를 잠글 수는 없습니다.

## 6. 위젯·확장 프로그램으로 등록
> 설치 절차 전체는 화면 메뉴얼 **결함 등록 위젯·확장 프로그램 설치**(`/manuals/defect-widget`, 파일 `public/manuals/defect-widget.html`)를 보세요. 결함관리 > 설정 > 테스트 벤치 탭에도 링크가 있습니다.
- **위젯**: 테스트 대상 사이트에 `<script src="{PMOTOOLS 주소}/defect-widget/pmo-defect-widget.js" data-pmotools-url="{PMOTOOLS 주소}" defer></script>`를 넣으면 "결함 등록" 버튼이 생깁니다. 선택 속성 `data-test-stage`, `data-case-id`로 단계·케이스를 미리 지정할 수 있습니다.
- **Chrome 확장**: Chrome 확장 관리에서 `defect_extension` 폴더를 "압축해제된 확장 프로그램"으로 불러오고, 옵션에서 PMOTOOLS 주소를 저장하고 접근 권한을 허용합니다. 아이콘을 누르면 현재 화면을 캡처해 등록 창이 열립니다.
- 두 방식 모두 대상 도메인에 등록된 사용 중인 주소에서만 동작합니다. 로그인이 안 되어 있으면 로그인 뒤 같은 창으로 돌아옵니다.

## 7. 개발자 점검
- `npm run defect:guard`: 단위테스트 경로·모델·마이그레이션이 바뀌지 않았는지 확인합니다.
- 서버 통합 검증은 마이그레이션을 적용한 임시 DB 주소를 `DEFECT_TEST_DATABASE_URL`로 주고 `npx vitest run lib/server/mp/defects/defects.integration.test.ts`를 실행합니다(운영·개발 DB에서는 실행 금지).
