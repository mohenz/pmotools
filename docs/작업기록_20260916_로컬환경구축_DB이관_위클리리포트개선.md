## 4. 위클리리포트 업무영역별 작성상태 수평 표 개선

사용자 요청에 따라 주간보고 상세 화면(`/weekly-reports/[weekId]`)의 UI/UX를 개선했습니다:

- **배치 위치**:
  - 상단 기간/현황 요약 카드(`weekly-report-summary`)와 하단 업무그룹 상세 테이블(`weekly-report-detail-panel`)의 중간에 배치.
- **가로 1개 라인 수평 표(Horizontal Table) 구조**:
  - 세로 다단으로 인한 스크롤 낭비를 없애고, **단 2개 행(약 68px 높이의 슬림한 띠)**으로 전 모듈을 한눈에 조망하도록 개선.
  - **1행 (헤더)**: 좌측 고정 라벨 `[업무영역]` + 12개 모듈명 가로 나열
  - **2행 (바디)**: 좌측 고정 라벨 `[작성상태]` + 12개 모듈별 상태 뱃지 가로 나열
  - 좌측 라벨 컬럼은 `position: sticky; left: 0;`로 고정하여 가로 스크롤 시에도 기준점 유지.
- **상태 뱃지 텍스트 간결화**:
  - 사용자 지시에 따라 `작성 완료` ➔ **`완료`**로 텍스트 축소.
  - 뱃지 분류: `완료` (녹색 뱃지), `작성 중` (주황색 뱃지), `미작성` (회색 대시 뱃지).
- **마이크로 인터랙션 (UX)**:
  - 표의 업무영역 명칭 클릭 시 하단 상세 테이블의 해당 행(`#report-[id]`)으로 스무스 스크롤 이동.
  - 해당 상세 행이 일시적으로 반짝이는 강조 효과(`highlight-row`) 애니메이션 적용.
- **다크/라이트 테마 일관성**:
  - 기존 CSS 변수 토큰(`--card`, `--border`, `--muted`, `--success-bg`, `--warning-bg`)을 재활용하여 일체감 있는 비주얼 완성.
