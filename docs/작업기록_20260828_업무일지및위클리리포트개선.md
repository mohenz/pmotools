# 업무일지 및 위클리리포트 개선 작업 기록

## 작업 일자

- 2026-08-28

## 주요 변경 사항

### 업무일지 관리

- 업무일지 목록, 등록, 상세, 수정 및 관리 화면을 추가했다.
- 업무그룹 리더가 담당 업무그룹 구성원의 업무일지를 조회할 수 있도록 권한과 조회 기능을 구현했다.
- 사용자 관리에서 업무그룹과 리더 정보를 지정할 수 있도록 관련 화면과 API를 보완했다.
- 업무일지 검색, 기간·진행상태 필터 및 내보내기 기능을 정리했다.
- 업무일지 사용 방법을 설명하는 HTML 메뉴얼을 작성하고 메뉴얼 메뉴에 연결했다.

### 위클리리포트 작성 및 수정

- 모달 방식의 작성·수정 흐름을 독립 페이지 방식으로 변경했다.
- 작성과 수정에 공통으로 사용하는 폼을 작업영역 너비에 따라 반응하도록 개선했다.
- 데스크톱에서는 실적과 계획을 2열로 표시하고, 태블릿·모바일에서는 1열로 자동 전환하도록 했다.
- 기존 1,100px 최대 너비 제한을 제거해 오른쪽 작업영역 전체를 사용할 수 있도록 했다.
- 모바일에서 입력창, 여백, 글자 크기와 취소·저장 버튼 배치를 최적화했다.

### 위클리리포트 조회, 인쇄 및 PDF

- 주차별 상세 화면의 `리포트 인쇄보기` 기능을 복원했다.
- PDF 파일 생성 기능을 주차별 상세 리포트에서 실행하도록 배치했다.
- 업무그룹별 아웃라인과 그룹 내용 구분선을 적용해 출력 문서의 구조를 명확하게 했다.
- 인쇄보기 표의 항목 셀은 연회색 배경과 진회색 글자, 내용 셀은 흰색 배경과 검정 글자로 고정했다.
- 다크 테마 및 PDF 인쇄에서도 글자와 배경의 명도 대비가 유지되도록 했다.

### AI 요약정보

- AI 요약의 각 불릿을 독립된 한 줄로 생성하도록 시스템 지시를 강화했다.
- 쉼표, 세미콜론 또는 공백으로 연결된 불릿을 저장 전에 실제 줄바꿈으로 정규화했다.
- 불릿 내용 내부에서 사용하는 일반 쉼표는 그대로 유지하도록 처리했다.
- 줄바꿈 정규화 동작을 검증하는 단위 테스트를 추가했다.

### 공통 UI

- PMO Daily 및 업무일지 필터를 한 줄형 인라인 필터로 정리했다.
- 업무일지 상세 화면의 WBS 값을 왼쪽 정렬했다.
- 오른쪽 작업화면이 브라우저와 작업영역 너비에 맞춰 유동적으로 조정되도록 공통 레이아웃을 개선했다.

## 데이터베이스 변경

- 업무일지 데이터를 저장하는 스키마와 마이그레이션을 추가했다.
- 사용자와 업무그룹의 리더·구성원 관계를 관리하는 스키마 및 마이그레이션을 반영했다.
- 메뉴명을 데이터로 관리하고 조회·수정할 수 있도록 메뉴 설정 관련 스키마를 보완했다.
