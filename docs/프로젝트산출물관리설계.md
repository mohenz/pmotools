1. 산출물 등록 및 검수 요청 진행시 산출물명과 검수자를 등록
2. 사용자의 프로젝트코드와 업무그룹코드가 자동 세팅되나 조회하여 변경할 수 있음
3. 단계는 기본 미분류
4. 문서번호는 산출물 표준에 의해 생성한 문서번호 입력 (중복가능)
5. 문서명을 입력하면 파일타입은 자동으로 선택됨
6. 문서링크는 쉐어포인트 링크를 복사하여 등록 (선택)
   (링크예: https://shinsegaegroup.sharepoint.com/:p:/s/U-TF-U-TFPMO2/IQADYuMiFHj0TaiQwSm-x4p0AS-MAjOuCf5cXCb1x1qavps?e=wmmB9K)
7. 1차 검수자는 업무그룹의 리더로 자동 지정되나 작성자와 업무그룹 리더가 동일하면 빈칸으로 남김
8. 검수자는 작성자가 수동을 선택하여 입력 (사용자 검색 기능 제공)
9. 검수자는 기본 3차까지 등록 가능하며 추가 기능으로 5차까지 추가 가능
10. 검수결과는 '대기, 요청, 진행, 적격, 보완요청, 부적격'으로 판단
11. 선정한 차수 전체가 적격이면 최종검수결과는 적격으로 판단 
12. 이전 차수가 완료되어야 다음 차수 검수자의 검사 진행 화면이 열림
13. 산출물 검수 이력은 차수별 검수자가 검수를 완료한 이후 검수결과 상태를 업데이트하면 기록을 남김
14. 산출물 관리 테이블의 정보는 1건 등록/수정, 엑셀 대량 등록/수정 가능하도록 기능 제공.
