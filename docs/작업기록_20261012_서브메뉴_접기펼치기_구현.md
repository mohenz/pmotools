## 1. 요구사항 및 배경
- **문제점**: WBS 목록(47개 컬럼), 간트 차트, 통계 매트릭스 등 데이터 집약적인 화면에서 좌측 2차 세부 메뉴(`.module-sidebar`, 고정 약 200px)가 상시 공간을 점유하여, 가로 해상도가 좁아지고 가로 스크롤 빈도가 높아지는 작업성 저하 문제 발생.
- **개선 목표**: 서브메뉴를 원클릭으로 접고 펼칠 수 있는 인터랙션을 추가하여, 본문 작업화면(`main#main-content`)의 가로 폭을 100% 최대로 확장할 수 있도록 개선.

## 2. 세부 구현 내역

### 1) 접기/펼치기 제어 및 UI 인터랙션
- **상태 관리 (`isCollapsed`)**:
  - `AuthenticatedAppShell.tsx`에서 React 상태(`useState`)로 관리.
  - 브라우저 로컬스토리지(`localStorage["pmo-sidebar-collapsed"]`)에 상태를 자동 동기화하여 페이지 이동 및 새로고침 후에도 사용자의 접음/펼침 상태 유지.
- **접기 버튼 (메뉴 펼쳐진 상태)**:
  - `.module-sidebar` 상단에 텍스트 및 툴팁 일체 없는 미니멀한 `PanelLeftClose` 순수 아이콘 버튼 배치.
- **펼치기 탭 (메뉴 접힌 상태)**:
  - 좌측 상단(`top: 124px, left: 0`)에 고정(`position: fixed`)된 슬림 도킹 아이콘 탭(`PanelLeftOpen`) 노출.
  - 텍스트 및 브라우저 기본 툴팁 노출 없이 깔끔한 아이콘으로만 화면 공간을 최소 점유하며, 화면 스크롤 상태에서도 즉시 사이드바를 재호출 가능.
- **단축키 지원 (`Ctrl + B` / `Cmd + B`)**:
  - 인풋/텍스트에디터 포커스 상태가 아닐 때 키보드 단축키 `Ctrl+B`로 즉시 메뉴 토글 가능.

### 2) CSS 트랜지션 및 본문 확장
- **애니메이션**: `transition: flex-basis 0.22s cubic-bezier(0.2, 0, 0, 1), width 0.22s ...` 적용으로 부드러운 여닫힘 모션 구현.
- **본문 100% 자동 확장**: 메뉴 접힘 시 사이드바의 너비가 0으로 축소되며, 우측 본문(`main.main`)이 화면 전체 너비로 자동 확장.
