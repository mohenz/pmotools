# 국경일·공휴일 데이터 (2026~2027)

`holidays` 테이블(전사 공통, `projectId` 비움)에 넣는 데이터입니다. 캘린더의 공휴일 표시와 WBS 영업일 계산이 이 테이블을 함께 씁니다.

- 출처: 공공데이터포털 한국천문연구원 특일 정보(`getRestDeInfo`) — 2026-11-01 조회, 46건
- 대체공휴일과 임시공휴일이 포함됩니다. 이름은 API 표기를 그대로 씁니다.
- 이 표는 `npx tsx scripts/sync-holidays.ts --file docs/holidays-2026-2027.md --apply`로 다른 PC의 DB에 그대로 넣을 수 있습니다. 절차는 [holidays-setup-guide.md](holidays-setup-guide.md)를 보세요.
- 표 형식(`| YYYY-MM-DD | 요일 | 이름 |`)을 바꾸지 마세요. 스크립트가 날짜와 이름 열을 읽습니다. 요일 열은 참고용입니다.
