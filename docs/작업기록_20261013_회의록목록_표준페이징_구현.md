# 작업기록: 회의록 전체 목록 표준 페이징 적용

- **작성일자**: 2026-10-13
- **작성자**: Rick Deckard (Strategic PMO Agent)
- **기준**: 요구사항관리 화면 페이징 규격 (회의록 Action Item 화면과 동일)

## 1. 적용 내용
- 표시 개수: 20(기본) / 40 / 60 / 80 / 100 / 전체 + [적용] 버튼
- 이전·다음, 최대 10개 페이지 번호, 현재 페이지 강조, `총 N건 · p / P 페이지` 요약
- 데이터가 1건 이상이면 페이징 바 상시 노출 (기존: 2페이지 이상일 때만 노출)
- 검색어·회의일 조건과 표시 개수는 페이지 이동 시 유지, 조회 시 페이지 1로 초기화
- 서버: 숫자 표시 개수는 10~100 범위로 제한, `all`은 전건 반환, 범위를 벗어난 페이지는 마지막 페이지로 보정
