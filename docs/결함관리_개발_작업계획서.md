## 7. 롤백 절차

- **코드:** 문제가 생긴 배포 커밋을 `git revert`한 새 커밋을 푸시한다.
- **신규 테이블:** 새 모듈은 신규 테이블 추가 중심이다. 롤백 시 신규 테이블 DROP은 승인 후 실행하며, 마이그레이션 이력(`_prisma_migrations`) 정리가 필요하다.
- 단위테스트와 defect_manage2는 변경하지 않으므로 롤백 대상이 아니다. 합산 통계(P8-03)는 읽기 전용 조회라 코드 되돌림만으로 원복된다.
