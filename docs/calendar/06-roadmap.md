# 06. 개발 로드맵

## Phase 0. 환경 셋업 (1주)
- GitHub 레포 생성, Next.js + TypeScript + Tailwind + shadcn/ui 초기화
- 로컬 PostgreSQL(Docker) 구성, Prisma 초기 스키마 작성
- Supabase 프로젝트 생성(Postgres/Storage), Vercel 프로젝트 연결(GitHub 연동, 브랜치별 Preview 자동 배포 확인)
- Auth.js Credentials Provider 기본 골격, 환경변수(.env) 체계 정리

## Phase 1. MVP (핵심 캘린더) (3~4주)
- 회원가입/로그인/로그아웃, 비밀번호 단방향 저장, 본인 비밀번호 변경
- 관리자: 사용자 목록 조회, 역할 변경, 강제 비밀번호 초기화
- 일정 CRUD (단기 일정만, 반복 제외), 등록 필드 전체 반영(우선순위/종일/시간/위치/메모)
- 월간/주간 뷰 (FullCalendar 연동)
- 프로젝트 정보 관리(기본 CRUD)
- 반응형 레이아웃 뼈대 (데스크톱 사이드바 + 모바일 하단 탭바)

## Phase 2. 협업 기능 확장 (3주)
- 년간/일간 뷰, 모바일 Agenda 뷰
- 반복 일정(RRULE) 등록/전개 + 단일회차 예외 처리
- 업무그룹/조직그룹 관리, 이벤트-담당자·업무그룹 다중 지정
- 주요 이벤트 모아보기(마일스톤), 프로젝트 오픈일자 자동 마일스톤 반영
- 일정 검색(키워드 + 필터 조합)
- 화면 테마(밝게/어둡게/시스템)

## Phase 3. 부가 기능 (3주)
- 엑셀 다운로드/업로드(월단위, 검증+오류 리포트 포함)
- 쪽지 기능(암호화 저장, 조회 비밀번호)
- 이메일 알림 (사용자 이메일 등록 UI 추가 → Resend/SMTP 연동 → 리마인더 발송)
- 알림 설정 화면(수신 여부/리마인더 시점)
- 첨부파일 업로드 (Supabase Storage)

## Phase 4. 운영 안정화 (2주)
- 감사 로그(활동 이력) 구현 및 관리자 조회 화면
- 성능 점검: Supabase Connection Pooling 적용, 인덱스 점검, 100명+ 동시접속 부하 테스트
- 보안 점검: RBAC 3중 체크(화면/버튼/API) 재검증, HTTPS/세션 정책, RLS 최소 방어선 설정
- 백업 정책(PITR) 설정, 모니터링(Vercel/Supabase Logs) 구성
- 사용자 매뉴얼 작성 및 파일럿(소그룹) 운영 → 전체 오픈

## 마일스톤 요약
| Phase | 기간(누적) | 산출물 |
|---|---|---|
| 0 | ~1주 | 개발 환경/배포 파이프라인 완성 |
| 1 | ~5주 | 로그인 + 기본 일정 CRUD + 월/주 뷰 동작 (내부 데모 가능) |
| 2 | ~8주 | 반복일정·그룹·검색·모바일 Agenda 포함 전체 뷰 완성 |
| 3 | ~11주 | 엑셀/쪽지/이메일 알림 등 부가기능 완성 |
| 4 | ~13주 | 감사로그/보안/성능 점검 후 정식 오픈 |
