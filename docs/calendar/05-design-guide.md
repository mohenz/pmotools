# 05. 디자인 가이드 (반응형 — PC 웹 / 모바일)

## 0. 방향성
첨부 참고 디자인(좌측 사이드바 + 컬러 코딩된 이벤트 블록 + 모바일 리스트뷰 구조, Notion Calendar 계열 스타일)의 **정보 구조**를 채택하되,
100명+ 사내 프로젝트 인력이 매일 사용하는 **업무 도구**라는 특성에 맞춰 파스텔 마케팅 톤 대신
**신뢰감 있는 뉴트럴 배경 + 절제된 포인트 컬러**로 톤을 조정합니다. (다크모드 지원 전제)

## 3. 레이아웃 & 그리드

### 3.1 브레이크포인트
| 구간 | 범위 | 레이아웃 |
|---|---|---|
| Mobile | ~767px | 1단, 하단 탭바, 리스트(Agenda) 기본 뷰 |
| Tablet | 768~1023px | 사이드바 아이콘 축소형(드로어 전환) |
| Desktop | 1024~1439px | 사이드바 고정(240px) + 본문 |
| Wide | 1440px~ | 사이드바 280px + 본문 최대폭 1200px 중앙 정렬 |

### 3.2 데스크톱 레이아웃 (첨부 디자인 구조 계승)
```
┌──────────────┬───────────────────────────────────────────┐
│  Sidebar     │  TopBar: [년/월/주/일 전환] [오늘] [검색] [+]│
│  - 미니 캘린더 ├───────────────────────────────────────────┤
│  - 주요이벤트  │                                             │
│    모아보기    │           캘린더 메인 뷰 영역                │
│  - 업무그룹    │      (월간 그리드 / 주간·일간 타임라인)        │
│    필터(색상)  │                                             │
│  - 프로젝트    │                                             │
│    선택        │                                             │
├──────────────┤                                             │
│ 설정/프로필    │                                             │
└──────────────┴───────────────────────────────────────────┘
```
- 사이드바 폭 240~280px, `--color-bg-subtle` 배경으로 본문과 시각적 분리
- 이벤트 블록: 좌측 4px 컬러 바(우선순위 또는 그룹색) + 제목 + 시간, `border-radius: 6px`
- 카드/모달 `border-radius: 12px`, 그림자는 `0 4px 16px rgba(0,0,0,0.08)` 수준으로 절제

### 3.3 모바일 레이아웃
```
┌───────────────────────────┐
│  ← 2026년 8월        검색🔍 │  TopBar (월 표시 + 검색)
├───────────────────────────┤
│  일 월 화 수 목 금 토        │  주간 스트립(가로 스크롤/스와이프)
├───────────────────────────┤
│  ● 회사 워크숍       종일     │
│  ● 요구사항 검토 회의 10:00  │  Agenda 리스트 (기본 뷰)
│  ● 배포 점검         14:00  │
├───────────────────────────┤
│  🏠     📅     🔍    ✉️   ⚙️ │  하단 탭바: 홈/캘린더/검색/쪽지/설정
└───────────────────────────┘
                    ⊕  (우하단 FAB: 일정 등록, 관리자/운영자만 노출)
```
- 모바일 기본 뷰는 **월간 그리드가 아닌 Agenda(목록)** — 첨부 디자인의 모바일 스크린샷과 동일한 접근으로, 좁은 화면에서 정보 밀도와 가독성을 동시에 확보
- 월/주/일 그리드 뷰는 상단 뷰 전환 메뉴로 진입 가능(터치 시 확대 스와이프)
- FAB(플로팅 버튼)는 관리자/운영자 로그인 시에만 노출 (일반 사용자는 등록 권한 없음)

## 4. 컴포넌트 가이드

| 컴포넌트 | 규칙 |
|---|---|
| 뷰 전환 세그먼트 컨트롤 | 년/월/주/일 4개 버튼, 선택 시 `--color-primary` 배경 + 흰 텍스트 |
| 이벤트 카드(그리드 내) | 좌측 컬러 바 4px + 제목 1줄 말줄임 + 시간(종일 시 "종일" 뱃지) |
| 우선순위 뱃지 | Pill 형태, 컬러 배경 10% opacity + 해당 컬러 텍스트, 아이콘(●) 병기 |
| 사이드바 미니 캘린더 | 오늘 날짜는 `--color-primary` 원형 강조, 일정 있는 날짜는 하단 dot 표시 |
| 업무그룹 필터 목록 | 체크박스 + 컬러 스와치 + 그룹명 (첨부 디자인의 "MY AVAILABILITY" 목록 구조 참고) |
| 일정 등록 모달 | 데스크톱: 중앙 모달(480px) / 모바일: 하단 바텀시트, 필드 순서는 01-requirements 3.3 표 순서 준수 |
| 쪽지 조회 | 목록에서 열람 클릭 시 비밀번호 입력 모달 → 통과 시 내용 표시 (내용은 목록에 절대 미리보기 노출 안 함) |
| 엑셀 업/다운로드 버튼 | 다운로드: 아웃라인 버튼 / 업로드: 파일 선택 → 검증 결과 테이블(성공/실패 행 하이라이트) 노출 후 최종 반영 버튼 |
| 다크모드 | `prefers-color-scheme` 감지 + 사용자 설정(밝게/어둡게/시스템) 우선 적용, 토큰 테이블(1.1) 기준 자동 전환 |

## 5. 접근성 & 반응형 원칙
- 모든 인터랙티브 요소 최소 터치 영역 **44x44px** (모바일 기준)
- 색상 대비 WCAG AA 이상 (본문 텍스트 대비 4.5:1)
- 우선순위/카테고리 정보는 **색상 단독으로 전달 금지** — 라벨/아이콘 병기
- 키보드 포커스 링 명시 (`outline: 2px solid var(--color-primary)`)
- 애니메이션은 모달 열림/닫힘, 뷰 전환 정도로 최소화(과도한 모션 지양), `prefers-reduced-motion` 대응
