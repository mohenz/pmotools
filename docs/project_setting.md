# Supabase 프로젝트 설정

- 프로젝트명: `projectmgmt`
- 프로젝트 URL: Supabase Dashboard의 **Project Settings → API**에서 확인
- Publishable key: 로컬 `.env.local` 또는 Vercel 환경변수에만 저장
- Secret key: Git, 문서, 클라이언트 코드에 저장하지 않음
- JWKS URL: `<SUPABASE_URL>/auth/v1/.well-known/jwks.json`

## GitHub

- 원격 저장소: `https://github.com/mohenz/projectmgmt.git`
