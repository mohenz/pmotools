# 작업 기록 — 요구사항 및 연간 캘린더 개선 (2026-08-18)

> 대상 저장소: `mohenz/pmotools`
> 개발 환경: Next.js 15, React 19, Prisma ORM 7, PostgreSQL 18
> 로컬 서비스: `http://localhost:3020`

## 1. 원격 변경 및 로컬 환경 반영

- `origin/main`의 신규 커밋 5개를 fast-forward 방식으로 반영했다.
- 로컬 PostgreSQL(`localhost:55432`)을 기동했다.
- 원격 변경에 포함된 Prisma 마이그레이션 6개를 로컬 DB에 적용했다.
- Prisma Client를 최신 스키마 기준으로 재생성했다.
- 로컬 개발 서버를 포트 `3020`에서 실행하고 로그인·요구사항 화면 응답을 확인했다.

## 2. 요구사항 데이터 동기화

운영 PMOTOOLS의 요구사항 데이터를 인증된 화면의 서버 렌더링 원본 객체에서 수집해 로컬 DB에 반영했다.

| 데이터 | 동기화 결과 |
|---|---:|
| 요구사항 | 171건 |
| 요구사항 이력 | 171건 |
| 변경요청 | 0건 |
| 고아 이력 | 0건 |
| 요구사항 번호 시퀀스 | 171 |

환경별 UUID가 달랐던 `기능` 공통코드는 `groupCode + label`을 기준으로 로컬 코드에 매핑했다. 운영 화면에서 노출되지 않는 이력의 `actorId`는 비워 두고 표시용 `actorName`을 보존했다.

동기화 전 로컬 요구사항 데이터는 `.local-backups/` 아래에 JSON으로 백업했으며, 운영 환경변수와 수집용 임시 파일은 작업 직후 삭제했다. 백업 파일은 로컬 전용으로 Git에 포함하지 않았다.

## 3. 요구사항 페이지네이션 개선

`/requirements` 목록의 페이지 번호 노출 범위를 최대 7개에서 최대 10개로 변경했다.

- 전체 페이지가 10개 이상이면 페이지 번호 10개 표시
- 전체 페이지가 10개 미만이면 존재하는 페이지만 표시
- 중간 구간에서는 현재 페이지 앞 4개, 뒤 5개를 기준으로 범위 계산
- 처음과 마지막 구간에서는 정확히 10개 범위를 유지하도록 보정

## 4. 연간 캘린더 화면 개편

`/calendar?view=year`의 단순 월별 카드 목록을 12개월 미니 달력으로 변경했다.

- 각 월을 월요일부터 일요일까지 7열 달력으로 표시
- 날짜별 일정 건수 배지 표시
- 오늘 날짜 강조
- 월 제목에서 월간 화면으로 이동
- 날짜에서 일간 화면으로 이동
- 토요일·일요일 색상 구분
- 데스크톱 3열, 태블릿 2열, 모바일 1열 반응형 배치
