## 1. 개요 및 요구사항

### 1) 배경
- 기존 상단 고정 버튼(아이콘 토글 버튼) 방식은 직관적이지만, 화면 너비를 사용자의 모니터 해상도 및 콘텐츠(WBS 다중 컬럼, 간트 차트 등)에 맞춰 유연하게 조절할 수 없는 한계가 존재함.
- Microsoft Teams, Slack, VS Code 등 글로벌 엔터프라이즈 협업 툴과 동일하게, **메뉴 영역과 본문 화면 영역 사이의 구분선을 마우스로 끌어당겨(드래그) 너비를 자유롭게 조절**하고, **접힌 상태에서는 슬림한 세로 레일 표시를 통해 손쉽게 펼치기**가 가능하도록 UX 개선 요청.

### 2) 핵심 인터랙션 요구사항
1. **스플리터 구분선 드래그 (Splitter Resizer)**:
   - 메뉴 영역(`.module-sidebar`)과 본문(`main#main-content`) 사이의 경계선을 좌우로 드래그하여 메뉴 너비를 150px ~ 420px 범위 내에서 실시간 조절.
   - 마우스 호버 시 경계선이 액센트 색상(`var(--primary)`)으로 하이라이트되며, 중앙에 팀즈 스타일의 슬림 썸(Pill Thumb) 핸들 노출.
2. **드래그 접기 (Drag to Collapse)**:
   - 왼쪽으로 일정 임계값(75px) 이하까지 밀어 넣으면 부드럽게 완전 접힘(Collapsed) 처리.
   - 구분선 더블 클릭 시 즉시 접힘 처리.
3. **접힌 상태에서의 펼치기 표시 (Teams Style Collapsed Rail)**:
   - 접힌 화면에서는 좌측 가장자리에 화면 간섭을 최소화하는 8px 슬림 세로 레일 배치.
   - 마우스 호버 시 14px로 살짝 확장되며 세로 중앙에 팀즈 스타일의 힌트 알약(Pill Handle)과 우측 셰브론(`ChevronRight`) 노출.
   - **원클릭**: 클릭 시 이전 너비(또는 기본 200px)로 즉시 복원.
   - **우측 드래그**: 오른쪽으로 마우스를 끌어당기면 당긴 만큼 즉시 실시간으로 사이드바가 펼쳐짐.
4. **상태 영속화 (State Persistence)**:
   - 조절된 너비(`pmo-sidebar-width`)와 접힘 여부(`pmo-sidebar-collapsed`)를 `localStorage`에 자동 보관하여 페이지 새로고침/이동 후에도 사용자 맞춤 상태 유지.
5. **키보드 접근성**:
   - `Ctrl + B` 단축키 토글 유지.
   - 구분선 포커스 시 `ArrowLeft`/`ArrowRight` 너비 증감 및 `Home`(접기)/`End`(초기화) 지원.

## 2. 세부 구현 내역

### 1) 컴포넌트 로직 (`AuthenticatedAppShell.tsx`)
- **상태 관리**:
  - `sidebarWidth`: 기본 200px (150px ~ 420px 클램프).
  - `isCollapsed`: boolean.
  - `isDragging`: 마우스 드래그 중 여부.
- **드래그 리사이징 제어 (`startResize`)**:
  - `mousemove`, `mouseup` 전역 이벤트를 통해 마우스가 화면 어디로 이동하더라도 끊김 없는 60fps 트래킹 보장.
  - 드래그 중 `body.resizing-sidebar` 및 `.app-body.resizing-active` 클래스를 추가하여 본문 마우스 이벤트 간섭 차단 및 `cursor: col-resize`, `user-select: none` 강제.
- **접힘 레일 제어 (`handleRailMouseDown`)**:
  - 클릭과 드래그를 정밀 판별(5px 이동 임계값).
  - 단순 클릭은 이전 너비 복원, 오른쪽 드래그는 실시간 확장 전환.

### 2) CSS 스타일링 (`globals.css`)
- **CSS 변수 기반 바인딩**:
  - `.app-body`에 `--sidebar-width` 인라인 속성을 부여하고, `.module-sidebar`가 `flex: 0 0 var(--sidebar-width)` 및 `width: var(--sidebar-width)`를 참조.
  - 드래그 중(`resizing-active`)일 때는 `transition: none`을 부여하여 즉각적인 마우스 추적 반응성 확보.
- **스플리터 (`.sidebar-splitter`)**:
  - `cursor: col-resize`, 상하 전체 높이 스티키 배치, 호버 시 `var(--primary)` 수직 바 및 원형 알약 핸들러 애니메이션.
- **접힘 레일 (`.sidebar-collapsed-rail`)**:
  - 좌측 가장자리에 0에 수렴하는 시각적 점유율 유지, 호버 시 팀즈 규격의 플로팅 힌트 캡슐(`.rail-handle-pill`) 부드럽게 노출.
