## 1. 주요 작업 내용 및 목적

### 1) 나의 WBS 현황 집계 누락 방지 (Fallback)
- **문제점**: 사용자가 4레벨(leaf) 작업이 없고 상위 요약·마일스톤 Task만 할당받은 경우, leaf 필터링으로 인해 집계 결과가 0건(진척율 0%)으로 왜곡되는 현상 발생.
- **개선 내용**:
  - `lib/server/wbs.ts`의 `getWbsOwnerStatus`에 fallback 로직 적용.
  - 리프 항목이 없을 경우, 본인에게 할당된 전체 Task를 대상으로 진척율(100%)과 상태를 정확히 합산 산출.
  - 단위 테스트(`lib/server/wbs-owner.test.ts`) 보강.

### 2) 10-Segment 게이지형 배터리 그래프 구현
- **요청 사항**: '나의 WBS 현황' 카드의 단순 막대 차트를 배터리 형태의 직관적인 게이지 그래프로 개편.
- **개선 내용**:
  - `components/PortfolioDomainCharts.tsx` 내 Chart.js 캔버스를 활용하여 10% 단위(총 10개 블록)로 충전되는 **배터리 게이지 UI** 구현.
  - 배터리 외곽 하우징, 양극(+) 단자 캡, 볼트 번개 아이콘 엠블럼, 진척율 동적 컬러 매핑(70% 이상 초록, 40~69% 황색, 40% 미만 적색) 및 중앙 퍼센트 텍스트 렌더링.

### 3) 에이전트 협업 체계 확립 (Eduardo Gaff 등록)

### 4) 세션 유휴 타임아웃 1시간 연장
- **요청 사항**: 실무자 및 관리자의 잦은 세션 만료 및 재로그인 불편 해소 (30분 ➔ 1시간).
- **개선 내용**:
  - `lib/domain/session.ts`: `SESSION_MAX_AGE_SECONDS`를 기존 `30 * 60`에서 `60 * 60` (1시간)으로 연장.
  - `app/login/page.tsx`: 유휴 시간 안내 문구("1시간") 동기화.
  - `lib/domain/session.test.ts`: 1시간(3,600초) 만료 규격 단위 테스트 추가.

### 5) 일반 사용자('MEMBER') 로그인 첫 화면 'MY일감'(`/portfolio`) 제공
- **문제점**: DB 메뉴 설정 상 `portfolio`('MY일감')는 일반 사용자에게 노출되어 있으나, 페이지 상단의 `requireManagerContext()`로 인해 일반 사용자가 접속 시 `/calendar`로 강제 리다이렉트되는 현상.
- **개선 내용**:
  - `app/portfolio/page.tsx`: `requireManagerContext()`를 `getLocalContext()`로 변경하여 일반 사용자 진입 전면 허용.
  - `screens/PortfolioScreen.tsx`: 일반 사용자 접속 시 본인 업무(나의 WBS 현황 배터리 차트 및 당면 과업 목록) 중심의 최적화된 레이아웃 표출.

### 6) WBS 전체목록 디폴트 완료제외 및 원클릭 토글 스위치 신설
- **요청 사항**: WBS 목록 화면(`/wbs`) 조회 시 실적 100% 완료된 과업은 기본 제외하고, '전체 상태' 옆에 토글을 신설하여 ON/OFF 제어 지원.
- **개선 내용**:
  - `lib/server/wbs.ts`: `WbsListFilters`에 `excludeCompleted` 필터 추가 (`actualProgress >= 1 || status === 'completed'` 대상 제외).
  - `app/wbs/page.tsx`: URL 파라미터가 없는 디폴트 진입 시 `excludeCompleted: true` 기본 부여.
  - `components/WbsExcludeCompletedToggle.tsx`: 원클릭 즉시 조회(`form.requestSubmit()`) 슬라이더 토글 컴포넌트 신설.
  - `screens/WbsListScreen.tsx`: '전체 상태' 드롭다운 우측 배치 및 페이징 링크/폼 파라미터 유지 연동.
  - `app/globals.css`: `.wbs-exclude-completed-toggle` 전용 슬라이더 스위치 CSS 스타일링.
