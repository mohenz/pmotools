PMOTOOLS WBS 상세내용 확장 프로그램 매뉴얼

  • 버전: 1.0.0 (2026-10-22)
  • 대상 브라우저: Microsoft Edge 116 이상 (Chrome 116 이상도 동일하게 사용 가능)
  • 대상 시스템: PMOTOOLS 운영 서버 http://10.147.148.101:3020

1. 무엇을 하는 프로그램인가

PMOTOOLS 화면을 열지 않고 브라우저 오른쪽 옆 패널에서 내가 담당인 WBS Task의 상세내용을 작성·저장합니다.

할 수 있는 일할 수 없는 일
내 담당 Task 목록 보기·검색, "상세내용 미작성"만 보기일정·진척률·담당자 수정 (PMOTOOLS 화면에서만)
상세내용 작성·수정 (최대 10,000자)다른 사람 담당 Task 수정 (PM/PMO 제외)
표준 템플릿 삽입하위 Task가 있는 상위 항목 수정
작성 중 내용 자동 임시 저장·복구
저장되는 곳은 PMOTOOLS WBS 항목의 "내용" 칸과 같습니다. 확장 프로그램에서 저장하면 PMOTOOLS WBS 화면에도 바로 반영됩니다.

2. 사용 전 확인

  1. 사내망에 연결되어 있어야 합니다.
  2. 같은 브라우저에서 PMOTOOLS에 로그인할 수 있어야 합니다(계정·프로젝트 배정).
  3. PMOTOOLS 서버에 확장 프로그램용 기능이 반영되어 있어야 합니다(관리자 확인 — 8장).

3. 설치 (Edge)

  1. 전달받은 PMOTOOLS_WBS상세내용_확장프로그램_v1.0.0.zip을 바꾸지 않을 폴더에 압축 해제합니다.
    • 예: D:\Tools\pmotools-wbs-ext\
    • 설치 후 이 폴더를 지우거나 옮기면 확장 프로그램이 사라집니다.
  2. Edge 주소창에 edge://extensions 입력 → 이동.
  3. 왼쪽 아래(또는 위) "개발자 모드" 를 켭니다.
  4. "압축을 푼 확장을 로드합니다" 클릭 → 1번 폴더 안의 wbs-detail 폴더를 선택합니다.
    • manifest.json 파일이 들어 있는 폴더를 선택해야 합니다.
    • 올바른 예: D:\Tools\pmotools-wbs-ext\wbs-detail (이 폴더를 열면 manifest.json이 바로 보여야 합니다)
    • "매니페스트 파일이 없거나 읽을 수 없습니다" 오류가 나면 한 단계 위 폴더를 선택한 것입니다. 안쪽의 wbs-detail 폴더를 다시 선택하세요.
  5. 목록에 "PMOTOOLS WBS 상세내용" 이 나타나면 설치 완료입니다.
    • ID가 pmmnfijljombghphkmaemjdbkndpjhfl 인지 확인합니다(다르면 서버가 요청을 거부합니다).
  6. 주소창 오른쪽 퍼즐 모양(확장) 아이콘 → "PMOTOOLS WBS 상세내용" 옆 눈(표시) 아이콘을 눌러 툴바에 고정합니다.
Chrome: 주소창에 chrome://extensions → 오른쪽 위 "개발자 모드" → "압축해제된 확장 프로그램을 로드합니다" (이후 동일)

4. 처음 설정

  1. 툴바의 파란 문서 아이콘을 누르면 오른쪽에 패널이 열립니다.
  2. 패널 오른쪽 위 ⚙(설정) → 접속 서버 확인
    • 업무용: 운영 — 10.147.148.101:3020 (기본값)
    • 개발자 시험용: 개발 — 이 PC(localhost:3020)
  3. 완료를 누릅니다.

5. 사용 방법

5.1 로그인

  • 패널에 "로그인이 필요합니다" 가 나오면 PMOTOOLS 로그인 버튼 → 새 탭에서 로그인 → 패널의 ↻(새로고침) 를 누릅니다.
  • 아이디·비밀번호는 확장 프로그램에 저장되지 않습니다. 브라우저의 PMOTOOLS 로그인 상태를 그대로 사용합니다.
  • 로그인은 1시간 동안 유지됩니다. 만료되면 같은 방법으로 다시 로그인합니다(작성 중 내용은 임시 저장되어 있습니다).

5.2 내 Task 찾기

  • 패널 위쪽에 로그인 아이디 · 현재 프로젝트가 표시됩니다. 프로젝트는 PMOTOOLS 화면에서 선택한 프로젝트를 따릅니다.
  • 목록에는 내가 담당자인 최하위 Task만 나옵니다.
  • 검색: Task 코드(예: 7.1.1)나 이름 일부를 입력합니다.
  • 상세내용 미작성만: 체크하면 아직 내용을 쓰지 않은 Task만 보입니다.
  • 각 Task에 미작성(노랑) / 작성됨(초록) 표시가 붙습니다.

5.3 상세내용 작성·저장

  1. 목록에서 Task를 누릅니다.
  2. 위쪽에 Task 번호·이름·담당자·계획 기간이 표시됩니다.
  3. 템플릿 삽입을 누르면 커서 위치에 표준 항목이 들어갑니다(기존 내용은 지우지 않습니다).
■ 작업 범위
■ 수행 절차
■ 산출물
■ 완료 기준(0/1 판정 근거)
■ 선행·의존 작업
  1. 내용을 작성합니다. 오른쪽 위에 글자 수(최대 10,000자)가 표시됩니다.
  2. 저장을 누르면 "저장했습니다."가 표시됩니다.
  3. PMOTOOLS에서 열기 ↗ 를 누르면 해당 Task 상세 화면이 새 탭으로 열립니다.

5.4 임시 저장과 복구

  • 입력하는 동안 내용이 이 PC 브라우저에 자동 임시 저장됩니다(아래에 "임시 저장됨 시각" 표시).
  • 저장하기 전에 패널을 닫았거나 로그인이 만료되어도, 같은 Task를 다시 열면 "임시 저장된 내용이 있습니다 [복구] [버리기]" 가 나옵니다.
  • 서버에 저장되면 임시 저장 내용은 자동으로 지워집니다.

5.5 다른 사람이 먼저 수정한 경우

같은 Task를 다른 사람(PM 등)이 먼저 저장했다면 저장이 막히고 노란 상자가 나옵니다.

버튼동작
최신 내용 불러오기서버의 최신 내용으로 바꿉니다. 내가 쓴 내용은 임시 저장에 남아 있어 복구로 다시 불러올 수 있습니다
내 내용으로 덮어쓰기확인 후 내 내용으로 저장합니다. 상대방 내용은 사라지므로 내용을 비교한 뒤 사용하세요

5.6 읽기 전용

담당자가 아니거나(PM/PMO 제외) 하위 Task가 있는 상위 항목이면 "읽기 전용" 안내가 나오고 저장 버튼이 꺼집니다.

7. 보안 안내

  • 확장 프로그램은 PMOTOOLS 주소(운영·이 PC)에만 접속할 권한이 있고, 다른 웹사이트 내용은 읽지 않습니다.
  • 아이디·비밀번호·인증 토큰을 저장하지 않습니다. 임시 저장 내용만 이 PC 브라우저 안에 보관됩니다.
  • 서버는 이 확장 프로그램(고정 ID)에서 온 요청만 받으며, 다른 웹페이지가 로그인 상태를 이용해 상세내용을 바꾸는 것을 막습니다.
  • 저장 시 PMOTOOLS WBS 이력("상세내용 수정 — 브라우저 확장 프로그램")과 감사 로그가 남습니다.

8. 관리자 안내

8.1 서버 반영

항목내용
소스pmotools 저장소 브랜치 feature/wbs-ext
추가 APIGET /api/v1/ext/wbs/me, GET /api/v1/ext/wbs/mine, GET /api/v1/ext/wbs/{id}, PATCH /api/v1/ext/wbs/{id}/description
DB 변경없음 (기존 wbs_items.description 사용)
환경변수(선택)WBS_EXT_IDS — 허용 확장 ID(쉼표 구분). 없으면 기본 ID pmmnfijljombghphkmaemjdbkndpjhfl
권한Task 담당자 또는 PM/PMO(직무)·관리자 이상 계정

8.2 확장 ID와 키

  • 확장 ID는 manifest.json의 key로 고정됩니다. key를 지우거나 바꾸면 ID가 달라져 서버가 거부합니다.
  • 정식 패키지(CRX) 서명용 개인키는 배포 담당자가 별도 보관합니다(zip에 포함하지 않음).

8.3 정식 배포(그룹 정책)

  1. 개인키로 CRX 패키지를 만들고 사내 웹 서버에 wbs-detail.crx와 update.xml을 올립니다.
  2. IT 부서에 Edge 정책 ExtensionInstallForcelist 등록을 요청합니다.
    • 값: pmmnfijljombghphkmaemjdbkndpjhfl;http://{사내 배포 주소}/update.xml
  3. 버전을 올릴 때는 manifest.json의 version을 올리고 CRX·update.xml을 교체합니다.
