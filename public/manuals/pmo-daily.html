PMO Daily 매뉴얼

프로젝트 공정현황을 일자별로 기록하고 지연 TASK, 진행 이슈 및 관리업무를 한 화면에서 점검하는 방법을 안내합니다.

1. 기능 개요

PMO Daily는 기준일마다 하나의 통제 기록을 저장합니다. 같은 일자를 다시 저장하면 중복 기록을 만들지 않고 기존 기록을 수정합니다.

일자별 기록

계획·실적·전체·완료 TASK 수와 자동 계산된 공정 지표를 날짜별로 보관합니다.

통합 점검

지연 TASK를 직접 관리하고 진행 중인 이슈와 관리업무 현황을 함께 확인합니다.

사용 권한
PM 또는 PMO 직책의 사용자가 메뉴를 이용할 수 있습니다. 저장·수정 권한이 없으면 프로젝트 관리자에게 역할을 확인해 달라고 요청하십시오.

2. 일자별 목록

경로: PMO Daily → 일자별 목록

① 기간 검색
시작일과 종료일을 입력하고 조회를 선택합니다. 초기화를 선택하면 전체 기간을 다시 표시합니다.
② 지표 확인
계획/실적 TASK, 공정률, 지연 TASK, 지연율, 전체/완료 TASK, 전체 공정률을 비교합니다.
③ 기록 열기
기준일 링크를 선택하면 해당 날짜의 상세 조회·수정 화면으로 이동합니다.
목록 항목의미
등록 지연 TASK해당 기준일에 직접 등록되어 보관 중인 지연 TASK 건수
작성자최초로 일자별 기록을 저장한 사용자
최종 수정공정현황이 마지막으로 갱신된 시각

3. 신규 작성

경로: PMO Daily → 신규 작성

  1. 기준일을 확인하거나 원하는 날짜로 변경합니다.
  2. 계획 TASK 수, 실적 TASK 수, 전체 TASK 수, 완료 TASK 수를 입력합니다.
  3. 자동 계산된 공정률·지연 TASK·지연율·전체 공정률을 확인합니다.
  4. 공정현황 저장을 선택합니다.
  5. 저장 후 해당 날짜의 상세 화면으로 이동했는지 확인합니다.
이미 저장된 기준일을 선택하면 신규 행이 추가되지 않고 기존 기록을 수정합니다. 날짜와 기존 수치를 반드시 확인하십시오.

4. 공정현황 입력과 계산

출력 순서항목입력·계산 기준
1계획 TASK 수기준일까지 계획된 TASK 누계 직접 입력
2실적 TASK 수기준일까지 실제 수행한 TASK 누계 직접 입력
3공정률실적 TASK 수 ÷ 계획 TASK 수 × 100
4지연 TASK계획 TASK 수 − 실적 TASK 수, 최소 0건
5지연율지연 TASK 수 ÷ 계획 TASK 수 × 100
6전체 TASK프로젝트 전체 TASK 수 직접 입력
7완료 TASK완료 처리된 전체 TASK 수 직접 입력
8전체 공정률완료 TASK 수 ÷ 전체 TASK 수 × 100
계획 TASK가 0이면 공정률과 지연율은 0%로 계산됩니다. 완료 TASK 수는 전체 TASK 수보다 클 수 없습니다.

5. 지연 TASK 관리

5.1 등록

  1. + TASK 추가를 선택합니다.
  2. 업무그룹, 계획(%), 실적(%), TASK 설명을 입력합니다.
  3. 계획 완료일과 담당자를 지정합니다.
  4. 지연사유와 대응방안을 기록하고 등록합니다.

5.2 상태와 수정

상태사용 기준
식별지연이 최초 확인되어 원인과 영향을 분석하는 단계
조치중담당자와 대응방안을 정하고 조치 중인 단계
정상화계획 대비 지연이 해소되어 정상 범위로 돌아온 단계
종료후속 조치와 확인이 모두 완료된 단계

각 TASK의 수정에서 내용·담당자·상태를 갱신할 수 있습니다. 삭제 전에는 대상 기준일과 TASK ID를 다시 확인하십시오.

상단의 “지연 TASK”는 계획·실적 TASK 수 차이로 자동 계산된 값입니다. 아래 “등록 지연 TASK”는 원인과 대응방안을 관리하기 위해 직접 등록한 상세 건수이므로 서로 다를 수 있습니다.

6. 이슈·관리업무 연계 현황

이슈관리

진행 중인 이슈의 ID, 이슈명, 업무그룹, 담당자, 상태와 최종 수정일을 확인합니다. ID를 선택하면 이슈 상세로 이동합니다.

관리업무현황

관리업무항목의 총점과 평가상태를 확인합니다. ID를 선택하면 프로젝트통합모니터링 상세로 이동합니다.

각 영역의 전체 보기를 선택하면 해당 기능의 전체 목록으로 이동합니다.

7. 일자별 조회·수정 관리

  1. 일자별 목록에서 수정할 기준일을 선택합니다.
  2. 기존 공정 수치와 등록된 지연 TASK를 확인합니다.
  3. 변경할 수치를 입력하고 공정현황을 저장합니다.
  4. 필요한 지연 TASK를 추가하거나 기존 TASK의 상태와 대응방안을 수정합니다.
  5. 목록으로 돌아가 최종 수정 시각과 지표가 반영됐는지 확인합니다.
일자 변경
상세 화면의 기준일 선택 영역에서 다른 날짜를 지정하면 해당 날짜를 작성하거나, 이미 존재하는 기록을 조회·수정할 수 있습니다.

8. 문제 해결

상황확인 및 조치
PMO Daily 메뉴가 보이지 않음내 정보의 직책이 PM 또는 PMO인지, 메뉴 설정에서 PMO Daily가 활성화됐는지 확인합니다.
저장이 되지 않음프로젝트 역할과 입력값을 확인합니다. 완료 TASK는 전체 TASK를 초과할 수 없습니다.
공정률이 0%로 표시됨계획 TASK 수 또는 전체 TASK 수가 0인지 확인합니다.
새 기록이 목록에 추가되지 않음같은 기준일의 기존 기록이 수정된 것은 아닌지 기준일과 최종 수정 시각을 확인합니다.
담당자를 선택할 수 없음사용자가 프로젝트 멤버로 활성 등록되어 있는지 확인합니다.
지연 TASK를 찾을 수 없음기간 필터와 기준일을 확인하고 해당 날짜의 상세 화면을 다시 엽니다.

9. 운영 체크리스트

일일 입력

  • □ 올바른 기준일 선택
  • □ 계획·실적 TASK 누계 확인
  • □ 전체·완료 TASK 누계 확인
  • □ 자동 계산 지표 확인
  • □ 공정현황 저장

통제 점검

  • □ 지연 TASK 원인 기록
  • □ 담당자와 대응방안 지정
  • □ 지연 TASK 상태 갱신
  • □ 진행 이슈 확인
  • □ 관리업무 위험·주의 항목 확인
