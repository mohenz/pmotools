PMOTOOLS · USER GUIDE

캘린더 매뉴얼

년간·월간·주간·일간·목록 조회와 일정 등록, 반복 일정, 검색 및 엑셀 기능을 안내합니다.

1. 화면 구성

조회 방식

  • 년간: 월별 일정 건수 확인
  • 월간: 날짜별 일정 요약
  • 주간·일간: 시간대와 일정 길이 확인
  • 목록: 월 단위 일정 일괄 조회

일정 구분

  • 우선순위 상·중·하 일정
  • 주간실적 목표일과 차주 계획
  • 이슈에서 파생된 일정
  • 주요 이벤트와 반복 일정
주간·일간 화면에서는 일정의 시작·종료 시각에 맞춰 블록 길이가 표시됩니다. 예: 15:00~17:00 일정은 2시간 높이로 표시됩니다.

2. 일정 조회

경로: 캘린더

① 보기 선택
년간, 월간, 주간, 일간 또는 목록을 선택합니다.
② 기간 이동
이전·오늘·다음 버튼으로 기준 날짜를 이동합니다.
③ 상세 확인
일정을 선택하면 일정 정보가 열립니다. 주간·일간의 빈 시간대 + 버튼으로 해당 시각에 새 일정을 등록할 수 있습니다.

3. 일정 등록 및 수정

관리자·운영자 경로: 캘린더 → + 일정 등록

항목설명
제목·유형일정 목적과 회의·마일스톤·업무 등 유형을 지정합니다.
시작·종료날짜와 시간을 10분 단위로 입력하고 종료가 시작보다 늦게 설정되었는지 확인합니다.
업무그룹·장소관련 업무그룹과 실제 또는 온라인 장소를 지정합니다.
우선순위상·중·하 중 업무 영향도에 맞게 선택합니다.
담당자·그룹 태그참여자와 관련 그룹을 연결합니다.
반복일·주·월·년 반복과 종료 조건을 지정합니다.
반복 일정의 수정·삭제 시 선택한 회차만 처리할지 전체 반복 일정을 처리할지 범위를 반드시 확인하십시오.

4. 검색·주요 이벤트·엑셀

  • 검색: 제목, 설명, 장소, 기간, 우선순위, 그룹, 담당자 조건으로 일정을 찾습니다.
  • 주요 이벤트: 마일스톤과 프로젝트 주요 일정을 날짜순으로 확인합니다.
  • 엑셀 내보내기: 월 단위 일정 데이터를 다운로드합니다.
  • 엑셀 가져오기: 파일 검증 결과를 확인한 후 등록합니다. 오류 행을 먼저 수정하십시오.

5. 운영 체크리스트

  • □ 시작·종료 날짜와 시간 확인
  • □ 종일 일정 여부 확인
  • □ 업무그룹·담당자·장소 확인
  • □ 반복 주기와 종료 조건 확인
  • □ 일정 겹침 및 주요 마감일 확인
  • □ 저장 후 올바른 보기에서 노출 확인
