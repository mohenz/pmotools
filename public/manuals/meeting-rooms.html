회의실 매뉴얼

회의실 일정 조회, 예약·취소와 관리자 회의실·정기예약 운영 절차를 안내합니다.

1. 권한별 기능

사용자

  • 운영 중 회의실과 예약 현황 조회
  • 회의실 예약 등록
  • 본인 예약 상세 확인 및 취소

관리자·운영자

  • 회의실 등록·수정·운영 중지·복구
  • 전체 예약 현황 관리
  • 정기예약 요청 검토 및 승인

2. 예약 현황 조회

경로: 회의실

① 날짜 선택
조회할 날짜 또는 주간 범위를 선택합니다.
② 회의실 확인
회의실명, 위치, 수용 인원과 지원 장비를 확인합니다.
③ 시간표 확인
예약 블록의 시작·종료 시간, 회의실과 목적을 확인합니다.
운영 중인 회의실만 일반 예약 화면에 표시됩니다. 필요한 회의실이 보이지 않으면 관리자에게 운영 상태를 문의하십시오.

3. 회의실 예약

항목확인 기준
회의실참석 인원, 위치와 필요한 장비에 맞는 회의실을 선택합니다.
날짜·시간운영시간 내에서 30분 단위로 시작과 종료를 선택합니다.
회의 목적다른 사용자가 용도를 알 수 있도록 간결하게 입력합니다.
참석자필요한 경우 참석자 또는 관련 정보를 입력합니다.
① 빈 시간 선택 → ② 예약 정보 입력 → ③ 등록 → ④ 시간표에서 예약 결과 확인
같은 회의실의 시간이 겹치면 예약할 수 없습니다. 등록 전 종료시간과 기존 예약을 다시 확인하십시오.

4. 예약 상세 및 취소

  • 시간표의 예약을 선택해 상세 내용을 확인합니다.
  • 본인 예약 또는 권한이 있는 예약에서 취소 기능을 사용합니다.
  • 취소 전 회의실, 날짜, 시간과 회의 목적을 확인합니다.
취소 주의
취소하면 해당 시간이 다시 예약 가능한 상태가 됩니다. 참석자에게 변경 사실을 별도로 안내하십시오.

5. 관리자 운영

경로: 설정 → 회의실 관리

  • 회의실 등록: 명칭, 유형, 위치, 수용 인원, 장비와 정렬 순서를 입력합니다.
  • 운영 중지: 더 이상 신규 예약을 받지 않을 회의실을 비활성화합니다.
  • 복구: 운영이 재개된 회의실을 활성 상태로 되돌립니다.
  • 정기예약 승인: 요청 주기, 기간, 시간과 충돌 여부를 확인한 후 승인 또는 반려합니다.
운영 중지 전에 향후 예약과 정기예약을 확인하고 예약자에게 변경 사항을 안내하십시오.

6. 운영 체크리스트

  • □ 참석 인원에 맞는 수용 규모인가?
  • □ 필요한 장비가 제공되는가?
  • □ 시작·종료 시간이 정확한가?
  • □ 기존 또는 정기예약과 충돌하지 않는가?
  • □ 취소·변경 내용을 참석자에게 안내했는가?
