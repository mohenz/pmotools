결함 등록 위젯·확장 프로그램 설치 메뉴얼

1. 어떤 방법을 쓰나

구분위젯Chrome 확장 프로그램
설치 위치테스트 대상 사이트의 HTML에 한 줄 추가(개발·관리자 작업)테스터의 Chrome에 설치(사이트 수정 불필요)
신고 방법화면 오른쪽 아래 빨간 벌레 버튼 클릭Chrome 툴바의 확장 아이콘 클릭
캡처 범위현재 보이는 화면(위젯 버튼은 제외)현재 보이는 탭 화면
추천 상황사이트를 직접 관리하고, 모든 테스터에게 같은 버튼을 보여 줄 때사이트를 고칠 수 없거나 여러 사이트를 오가며 테스트할 때

두 방법 모두 같은 결함 등록 팝업이 열리고, 주소·화면명·메뉴명·브라우저 정보와 캡처가 자동으로 채워집니다.

2. 사전 준비

① PMOTOOLS 주소 확인
PMOTOOLS에 접속하는 주소(예: http://localhost:3020)를 확인합니다. 아래에서 {PMOTOOLS 주소}는 이 주소입니다.
② 테스트 대상 사이트를 "대상 도메인"에 등록 (운영자·PMO·관리자)
경로: 결함관리 → 설정 → 대상 도메인. 사이트 이름과 주소(예: http://localhost:8080)를 추가하고 사용 상태로 둡니다. 등록되지 않은 주소에서 보낸 캡처·화면 정보는 받지 않습니다.
주소는 프로토콜·호스트·포트까지 정확히 같아야 합니다. localhost:8080과 127.0.0.1:8080은 서로 다른 주소입니다. PMOTOOLS와 같은 주소에서 제공되는 테스트 벤치는 따로 등록하지 않아도 됩니다.
③ PMOTOOLS 로그인
등록 팝업은 PMOTOOLS 로그인 세션을 사용합니다. 로그인이 안 되어 있으면 팝업에서 로그인하고, 로그인 뒤 같은 등록 화면으로 돌아옵니다. 대상 프로젝트는 PMOTOOLS에서 현재 선택한 하위 프로젝트가 사용됩니다.
④ 팝업 허용
위젯은 새 창(팝업)으로 등록 화면을 엽니다. 테스트 대상 사이트에서 팝업이 차단되면 주소창의 팝업 차단 표시를 눌러 항상 허용으로 바꿉니다.

3. 위젯 설치

테스트 대상 사이트의 모든 페이지(또는 공통 레이아웃)의 </body> 바로 위에 아래 한 줄을 넣습니다.

<script src="{PMOTOOLS 주소}/defect-widget/pmo-defect-widget.js" data-pmotools-url="{PMOTOOLS 주소}" defer></script>

예: <script src="http://localhost:3020/defect-widget/pmo-defect-widget.js" data-pmotools-url="http://localhost:3020" defer></script>

결함관리 → 설정 → 테스트 벤치 탭에 현재 서버 주소로 채워진 코드가 나오니 그대로 복사해도 됩니다.

선택 설정

속성설명
data-test-stage결함 등록 시 테스트 단계를 미리 선택합니다(단계 코드 또는 이름, 예: 통합). 비우면 기본 단계가 선택됩니다.
data-case-id단위테스트 케이스 ID를 미리 연결합니다. 비우면 독립 결함으로 등록됩니다.
data-menu-name / data-screen-name메뉴명·화면명을 직접 지정합니다. 비우면 페이지의 제목(h1 등)에서 자동으로 읽습니다.
data-button="none"기본 벌레 버튼을 만들지 않습니다. 사이트의 자체 버튼에서 window.PmoDefectWidget.open()을 호출합니다.

페이지 <head>에 <meta name="pmo:menu-name" content="…">, <meta name="pmo:screen-name" content="…">를 넣어 화면 정보를 지정할 수도 있습니다.

설치 확인 — 페이지를 새로 고치면 오른쪽 아래에 빨간 벌레 버튼이 나타납니다. 캡처용 라이브러리(html2canvas-pro)는 첫 신고 때 인터넷(jsDelivr)에서 내려받으므로 외부 접속이 막힌 환경에서는 캡처가 빠진 채 등록 창이 열립니다.

4. 확장 프로그램 설치

Chrome 계열 브라우저(Chrome 116 이상)에서 압축해제된 확장 프로그램으로 설치합니다.

  1. 확장 프로그램 폴더를 준비합니다. 프로젝트의 defect_extension 폴더(예: D:\workspace\pmotools\defect_extension)를 테스터 PC에 복사합니다. 폴더 안에는 manifest.json, background.js, options.html, options.js가 있어야 합니다.
  2. Chrome 주소창에 chrome://extensions를 입력해 확장 프로그램 관리 화면을 엽니다.
  3. 오른쪽 위 개발자 모드를 켭니다.
  4. 압축해제된 확장 프로그램을 로드합니다를 누르고 defect_extension 폴더를 선택합니다. 목록에 "PMOTOOLS 결함 등록"이 나타납니다.
  5. 툴바의 퍼즐 아이콘에서 "PMOTOOLS 결함 등록"의 고정(핀)을 눌러 아이콘을 항상 보이게 합니다.
  6. 확장 프로그램 카드의 세부정보 → 확장 프로그램 옵션(또는 아이콘 우클릭 → 옵션)을 엽니다.
  7. PMOTOOLS 주소에 접속 주소(예: http://localhost:3020)를 입력하고 저장을 누릅니다.
  8. 저장 시 나타나는 해당 사이트 접근 허용 창에서 허용합니다. 허용해야 등록 창에 캡처와 화면 정보를 전달할 수 있습니다.
업데이트·재설치 시
폴더의 파일이 바뀌면 chrome://extensions에서 해당 확장의 새로고침(↻)을 누르고, 옵션에서 PMOTOOLS 주소를 한 번 더 저장해 권한을 다시 허용합니다. 폴더를 옮기거나 삭제하면 확장이 사라지므로 고정된 위치에 두십시오.
주의 — Chrome이 개발자 모드 확장에 대해 시작할 때 경고를 보여 줄 수 있습니다. 사내 테스트용 설치이므로 그대로 유지합니다. 확장은 PMOTOOLS 주소에만 접근 권한을 요청하고, 테스트 사이트의 화면은 아이콘을 누른 탭에서만 읽습니다.

5. 결함 신고하기

  1. 테스트 대상 사이트에서 오류가 보이는 화면을 띄웁니다.
  2. 위젯: 오른쪽 아래 빨간 벌레 버튼을 누릅니다. / 확장: 툴바의 "PMOTOOLS 결함 등록" 아이콘을 누릅니다.
  3. 결함 등록 팝업이 열립니다. 필요하면 로그인합니다.
  4. 자동으로 채워진 내용을 확인합니다 — 제목([화면명] 결함 보고), 테스트 단계, 화면 URL, 화면명·메뉴명, 환경(브라우저 정보), 증적 아래의 캡처 미리보기.
  5. 제목을 구체적으로 고치고(5자 이상), 심각도·우선순위·재현 단계를 입력합니다. 화면 목록에 등록된 URL이면 화면경로 적용 제안이 나타납니다.
  6. 결함 등록을 누르면 저장되고 팝업이 닫힙니다.
  • 증적은 결함당 최대 3개, 파일당 20MB입니다. 캡처가 마음에 들지 않으면 삭제하고 Ctrl+V로 직접 붙여넣거나 파일을 올릴 수 있습니다.
  • 취소하면 수집한 임시 데이터가 지워지고 팝업이 닫힙니다.
  • 등록한 결함은 결함관리 → 결함 목록에서 볼 수 있습니다. 담당자는 연결된 WBS Task의 작업자가 기본값입니다.

6. 문제 해결

증상원인과 조치
버튼이 보이지 않는다(위젯)스크립트 주소가 틀렸거나 페이지 캐시입니다. 브라우저 개발자 도구(F12) → Network에서 pmo-defect-widget.js가 200으로 받아지는지 확인하고 강력 새로고침(Ctrl+F5)합니다.
"팝업이 차단되었습니다"대상 사이트의 팝업을 허용합니다(2장 ④).
"…는 대상 도메인으로 등록되어 있지 않습니다"결함관리 → 설정 → 대상 도메인에 해당 사이트 주소를 등록하고 사용 상태인지 확인합니다. 포트까지 같아야 합니다.
"화면 캡처가 전달되지 않았습니다"캡처에 실패했습니다. 외부 라이브러리 접속이 막혔거나 사이트의 이미지 보안(CORS) 때문일 수 있습니다. Ctrl+V로 직접 붙여넣거나 파일로 올립니다. 위젯 대신 확장 프로그램은 탭 화면을 그대로 캡처하므로 이런 제한이 적습니다.
확장 아이콘을 눌러도 옵션 페이지만 열린다PMOTOOLS 주소에 대한 접근 허용이 없는 상태입니다. 옵션에서 주소를 저장하고 허용합니다(4장 7~8단계).
확장 아이콘이 반응하지 않는다chrome://, 확장 스토어, PDF 뷰어 등은 캡처할 수 없습니다. 일반 http/https 페이지에서 눌러 주십시오.
등록 팝업이 로그인 화면으로 간다정상입니다. 로그인하면 같은 등록 화면으로 돌아오며 캡처가 다시 채워집니다. 위젯을 연 원래 페이지는 닫지 마십시오.
"하위 프로젝트를 선택해 주세요"결함은 하위 프로젝트 단위로 등록합니다. PMOTOOLS 본 화면 상단의 대상 프로젝트를 하위 프로젝트로 바꾼 뒤 다시 신고합니다.

7. 체크리스트

  • ☐ 테스트 대상 사이트를 대상 도메인에 등록했다(사용 상태)
  • ☐ (위젯) 스크립트 한 줄을 넣고 벌레 버튼이 보인다
  • ☐ (확장) 개발자 모드로 로드하고, 옵션에서 주소를 저장하며 접근을 허용했다
  • ☐ 팝업 차단을 해제했다
  • ☐ 신고해 보니 제목·화면 URL·캡처 미리보기가 채워졌다
  • ☐ 등록 후 결함 목록에서 결함을 확인했다

샘플로 시험하려면 결함관리 → 설정 → 테스트 벤치 탭의 접속 경로를 사용하십시오.
