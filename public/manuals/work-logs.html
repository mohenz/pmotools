업무일지 메뉴얼

개인별 일일 업무내용을 기록하고, 업무그룹 리더와 관리자가 담당 그룹의 업무일지를 조회하는 절차를 안내합니다.

대상: 전체 사용자 / 업무그룹 리더 / 관리자·운영자기준 화면: 업무일지작성일: 2026-08-28

1. 기능 개요

업무일지는 담당자가 업무일자별 작업 내용, WBS 번호, 진행상태와 참고사항을 기록하는 기능입니다.

개인 기록

본인의 업무그룹으로 일지를 작성하고 자신의 기록만 수정합니다.

그룹 관리

업무그룹 리더는 담당 그룹, 관리자·운영자는 전체 그룹의 일지를 조회합니다.

기본 원칙
조회 범위가 넓어져도 수정 권한은 작성자 본인에게만 있습니다. 리더와 관리자는 다른 사용자의 일지를 열람할 수 있지만 대신 수정할 수 없습니다.

2. 사용 전 설정

설정담당확인 내용
업무그룹 생성관리자설정 → 그룹 관리에서 유형이 업무그룹인 활성 그룹을 생성합니다.
사용자 업무그룹 지정관리자설정 → 사용자 관리에서 사용자에게 업무그룹을 지정합니다.
업무그룹 리더 지정관리자설정 → 그룹 관리에서 업무그룹의 리더를 지정합니다.
사용자에게 활성 업무그룹이 지정되지 않으면 업무일지를 작성할 수 없습니다. 먼저 사용자 관리에서 업무그룹을 지정하십시오.

3. 업무일지 작성

경로: 업무일지 → 업무일지 작성

  1. 상단의 담당자와 지정 업무그룹을 확인합니다.
  2. 업무일자를 선택합니다.
  3. 연계할 WBS 번호를 입력합니다. 해당 항목이 없으면 비워 둘 수 있습니다.
  4. 진행상태를 진행중 또는 완료로 선택합니다.
  5. 업무내용을 필수로 작성합니다.
  6. 필요하면 참고내용과 비고를 작성하고 저장합니다.
항목입력 기준
업무일자실제로 업무를 수행한 날짜
WBS 번호프로젝트 작업분류체계 번호, 최대 100자
업무내용수행 작업과 결과를 구체적으로 기록하는 필수 항목
참고내용관련 문서, 협의 내용, 후속 작업 등
비고추가 공유사항이나 특이사항

4. 내 업무일지 조회

경로: 업무일지 → 업무일지 목록

① 검색
번호·WBS·업무내용 검색어를 입력합니다.
② 기간과 상태
시작일, 종료일과 진행상태를 선택하고 조회합니다.
③ 상세 열기
목록의 업무일지 번호를 선택해 상세 내용을 확인합니다.

개인 목록에는 로그인한 사용자가 작성한 업무일지만 표시됩니다. 초기화를 선택하면 모든 검색 조건이 제거됩니다.

5. 상세 조회와 수정

상세 화면에서 번호, 업무일자, 업무그룹, 담당자, WBS 번호, 진행상태, 업무내용과 작성·수정 시각을 확인합니다.

수정 절차

  1. 본인이 작성한 상세 화면에서 수정을 선택합니다.
  2. 변경할 내용을 입력하고 저장합니다.
  3. 상세 화면으로 돌아온 뒤 최종 수정 시각과 변경 내용을 확인합니다.
동시 수정 보호
다른 화면에서 같은 일지가 먼저 수정되면 저장이 거부될 수 있습니다. 상세 화면을 새로 열어 최신 내용을 확인한 후 다시 수정하십시오.

6. 업무일지 관리

경로: 업무일지 → 업무일지 관리

업무그룹 리더

본인이 리더로 지정된 활성 업무그룹의 일지만 조회할 수 있습니다.

관리자·운영자

프로젝트의 모든 활성 업무그룹 일지를 조회할 수 있습니다.

검색어, 기간, 업무그룹, 담당자, 진행상태를 조합해 조회합니다. 목록의 번호를 선택하면 해당 일지의 상세 화면이 열리고, 목록으로를 선택하면 관리 화면으로 돌아갑니다.

업무일지 관리 메뉴는 관리자·운영자 또는 하나 이상의 활성 업무그룹 리더에게만 표시됩니다.

7. 권한 기준

사용자 유형개인 목록관리 목록상세 조회수정
일반 사용자본인 기록사용 불가본인 기록본인 기록
업무그룹 리더본인 기록리더 담당 그룹본인 및 담당 그룹본인 기록
관리자·운영자본인 기록전체 업무그룹프로젝트 전체본인 기록

8. 문제 해결

상황확인 및 조치
업무일지를 작성할 수 없음사용자 관리에서 활성 업무그룹이 지정됐는지 확인합니다.
업무일지 관리 메뉴가 보이지 않음관리자·운영자 역할인지, 그룹 관리에서 업무그룹 리더로 지정됐는지 확인합니다.
그룹 일지가 보이지 않음리더로 지정된 그룹과 일지의 업무그룹이 같은지, 그룹이 활성 상태인지 확인합니다.
다른 사용자의 수정 버튼이 없음정상 동작입니다. 업무일지는 작성자 본인만 수정할 수 있습니다.
검색 결과가 없음기간, 상태, 업무그룹, 담당자 필터를 초기화한 뒤 다시 조회합니다.
저장 시 충돌 메시지가 표시됨상세 화면을 새로고침해 최신 버전을 확인한 후 다시 수정합니다.

9. 운영 체크리스트

작성자

  • □ 업무일자 확인
  • □ 업무그룹 확인
  • □ WBS 번호 확인
  • □ 진행상태 갱신
  • □ 업무내용과 결과 기록

리더·관리자

  • □ 조회 기간 확인
  • □ 업무그룹·담당자 필터 확인
  • □ 미완료 업무 확인
  • □ 참고내용·비고 확인
  • □ 필요한 후속 조치 공유
