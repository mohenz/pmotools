1. 기능 개요

위클리리포트는 선택한 월·주차를 기준으로 활성 업무그룹별 실적, 계획, 이슈 및 요청사항을 취합하는 기능입니다.

실적 기간

선택한 계획 주차의 전주 월요일~금요일입니다.

계획 기간

선택한 주차의 월요일~금요일입니다.

생성 기준
리포트 생성 시 그룹 관리에서 활성 상태인 업무그룹만 포함됩니다. 비활성 업무그룹은 신규 리포트에 생성되지 않습니다.

기본 업무 흐름

  1. 관리자가 연도·월·주차를 선택하여 위클리리포트를 생성합니다.
  2. 업무그룹 담당자가 배정된 모듈의 실적·계획·이슈를 작성합니다.
  3. 관리자가 작성 현황과 내용을 검토합니다.
  4. 관리자가 PM 확인을 실행하여 내용을 확정하고 입력을 잠급니다.
  5. 필요한 경우 인쇄 화면에서 보고서를 출력하거나 PDF로 저장합니다.

  • 리포트 검색·상세 조회·인쇄

일반 사용자

  • 리포트 목록 및 상세 조회

  • 인쇄 화면 조회
  • PM 확인 완료 후 읽기 전용 조회
업무그룹 배정
일반 사용자는 사용자-그룹 매핑으로 배정된 업무그룹만 수정할 수 있습니다. 수정 버튼이 나타나지 않으면 관리자에게 업무그룹 배정 상태를 확인해 달라고 요청하십시오.

3. 관리자 매뉴얼

3.1 생성 전 준비

  • 설정 > 그룹 관리에서 업무그룹 명칭과 활성 상태를 확인합니다.
  • 사용자별 담당 업무그룹이 올바르게 배정되어 있는지 확인합니다.
  • 생성하려는 월·주차의 리포트가 이미 존재하는지 확인합니다.

3.2 위클리리포트 생성

경로: 설정 → 위클리리포트 관리

  1. 연도, 월, 주차를 선택합니다.
  2. 화면에 표시되는 실적 기간과 계획 기간을 확인합니다.
  3. 위클리 리포트 생성을 선택합니다.
  4. 생성이 완료되면 해당 리포트의 상세 화면으로 이동합니다.
같은 프로젝트·주차의 리포트는 중복 생성할 수 없습니다. “이미 생성되어 있습니다”라는 메시지가 나타나면 관리 목록에서 기존 리포트를 조회하십시오.

3.3 전체 작성 현황 검토

경로: 위클리리포트 → 리포트 목록 → 리포트명

항목확인 내용
작성 현황완료 모듈 수 / 전체 모듈 수를 확인합니다.
실적해당 기간에 완료하거나 진행한 업무를 확인합니다.
계획다음 주 수행 계획과 목표를 확인합니다.
이슈 및 요청사항의사결정, 지원 또는 조치가 필요한 내용을 확인합니다.

업무그룹명을 선택하면 작성 창이 열립니다. 관리자·운영자는 모든 업무그룹을 수정할 수 있습니다.

3.4 PM 확인 및 확인 취소

  1. 상세 화면에서 모든 업무그룹의 내용을 검토합니다.
  2. PM 확인을 선택하고 확인 메시지에 동의합니다.
  3. 상태가 PM 확인 완료로 변경되었는지 확인합니다.
확정 효과
PM 확인 완료 상태에서는 모든 사용자의 입력이 잠깁니다. 수정이 필요하면 관리자가 PM 확인 취소를 선택해 상태를 다시 작성 중으로 변경해야 합니다.

3.5 리포트 삭제

경로: 설정 → 위클리리포트 관리 → 삭제

  1. 검색창에서 리포트명 또는 프로젝트명으로 대상을 찾습니다.
  2. 삭제할 리포트의 기간과 상태를 다시 확인합니다.
  3. 삭제를 선택하고 경고창에서 최종 확인합니다.
삭제 주의
해당 주차의 업무그룹별 위클리리포트가 모두 삭제되며 복구할 수 없습니다. 같은 주차의 주간실적과 인력변동 데이터는 유지됩니다.

4. 사용자 매뉴얼

4.1 리포트 찾기

경로: 위클리리포트 → 리포트 목록

  1. 리포트명 또는 프로젝트명을 검색합니다.
  2. 실적 기간, 계획 기간, 작성 현황과 상태를 확인합니다.
  3. 리포트명을 선택하여 상세 화면을 엽니다.

4.2 담당 업무그룹 작성

  1. 상세 표에서 본인의 담당 업무그룹을 찾습니다.
  2. 클릭하여 작성이 표시된 업무그룹명을 선택합니다.
  3. 실적, 계획, 이슈 및 요청사항을 작성합니다. 각 항목은 최대 2,000자입니다.
  4. 저장을 선택한 후 상세 표에 내용이 반영됐는지 확인합니다.
작성 권장 방식
실적과 계획은 업무 단위로 줄을 나눠 작성하고, 완료 여부·목표일·담당자를 구체적으로 표시하십시오. 이슈에는 필요한 의사결정이나 지원 요청을 함께 적는 것이 좋습니다.

4.3 수정이 불가능한 경우

  • 리포트 상태가 PM 확인 완료인지 확인합니다.
  • 본인이 해당 업무그룹에 배정되어 있는지 확인합니다.
  • 다른 주차의 리포트를 열지 않았는지 실적·계획 기간을 확인합니다.

5. 상태와 작성 기준

상태의미수정 가능 여부
작성 중업무그룹별 내용을 입력·검토하는 단계관리자 전체 가능, 일반 사용자는 배정 모듈만 가능
PM 확인 완료관리자가 검토하고 확정한 단계모든 사용자 수정 불가

작성 완료 집계 기준

업무그룹의 실적과 계획이 모두 입력되어야 작성 완료 모듈로 집계됩니다. 이슈가 없으면 이슈 및 요청사항은 비워둘 수 있습니다.

6. 조회 및 인쇄

  1. 리포트 상세 화면 오른쪽 위의 인쇄 화면을 선택합니다.
  2. 업무그룹별 실적, 계획, 이슈 및 요청사항을 최종 확인합니다.
  3. 브라우저의 인쇄 기능 Ctrl + P를 실행합니다.
  4. 프린터로 출력하거나 대상을 “PDF로 저장”으로 선택합니다.
인쇄 화면은 선택한 주차의 업무그룹별 내용을 순서대로 표시합니다. 출력 전에 빈 항목과 리포트 주차를 확인하십시오.

7. 문제 해결

상황확인 및 조치
생성 버튼을 사용할 수 없음선택한 월에 해당 주차가 존재하는지 확인합니다.
활성 업무그룹이 없다는 메시지그룹 관리에서 최소 1개 업무그룹을 활성화합니다.
이미 생성된 리포트라는 메시지위클리리포트 목록 또는 관리 목록에서 같은 주차를 검색합니다.
업무그룹을 수정할 수 없음PM 확인 상태와 사용자-업무그룹 배정을 확인합니다.
작성 현황이 완료로 증가하지 않음해당 모듈의 실적과 계획이 모두 입력되었는지 확인합니다.
리포트가 목록에 보이지 않음검색어를 지우고 페이지를 이동하거나, 관리자에게 생성 여부를 확인합니다.
