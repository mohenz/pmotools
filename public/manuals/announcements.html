PMOTOOLS · USER GUIDE

공지사항 매뉴얼

사용자의 공지 조회와 관리자·운영자의 등록, 수정, 게시 및 삭제 절차를 안내합니다.

1. 권한별 기능

일반 사용자

  • 공지사항 목록 검색·조회
  • 중요 공지와 게시 기간 확인
  • 상세 내용 및 조회 정보 확인

관리자·운영자

  • 공지사항 등록·수정·삭제
  • 중요 공지 지정
  • 공개 대상과 게시 기간 설정
  • 대시보드 노출 설정

2. 공지사항 조회

경로: 공지사항 → 공지사항 조회

① 검색
제목 또는 내용의 검색어를 입력하고 조회합니다.
② 목록 확인
중요 표시, 제목, 작성자, 게시일과 조회 수를 확인합니다.
③ 상세 조회
제목을 선택해 본문과 게시 정보를 확인합니다.
중요 공지는 목록 상단 또는 강조된 형태로 표시될 수 있습니다. 관리자 전용 공지는 권한이 있는 사용자에게만 노출됩니다.

3. 공지사항 등록

경로: 공지사항 → 공지사항 등록

항목작성 기준
제목공지 목적과 대상을 한 문장으로 명확히 작성합니다.
내용배경, 주요 내용, 적용일, 사용자 조치사항, 문의처 순서로 작성합니다.
공개 대상전체 사용자 또는 관리자 대상 여부를 선택합니다.
중요 공지즉시 확인이 필요한 공지에만 지정합니다.
게시 기간게시 시작일과 종료일을 업무 일정에 맞춰 지정합니다.
대시보드 노출메인 화면에서도 안내해야 하는 공지에 설정합니다.
① 필수 항목 입력 → ② 옵션 확인 → ③ 등록 → ④ 목록과 상세 화면에서 게시 결과 확인

4. 수정 및 삭제

  • 상세 화면의 수정 기능에서 내용을 변경한 뒤 저장합니다.
  • 게시 대상이나 기간을 바꾸면 실제 노출 범위가 달라지므로 다시 확인합니다.
  • 삭제 전 공지 제목과 게시 기간을 확인합니다.
삭제 주의
삭제된 공지는 사용자 목록에서 조회할 수 없습니다. 수정으로 해결할 수 있는 경우에는 삭제보다 수정을 우선하십시오.

5. 운영 체크리스트

  • □ 제목만으로 공지 목적을 알 수 있는가?
  • □ 적용일과 사용자 조치사항이 명확한가?
  • □ 공개 대상과 중요 여부가 올바른가?
  • □ 게시 시작·종료일이 올바른가?
  • □ 등록 후 일반 사용자 관점에서 노출을 확인했는가?
