1. 기능 개요

요구사항 엑셀관리는 요구사항정의서 전체를 엑셀 파일로 내려받거나, 표준 서식 파일을 올려 대량으로 반영하는 관리자·운영자 전용 화면입니다.

요구사항 ID 매칭 동기화

업로드한 파일이 곧 "요구사항 전체 목록"이 됩니다. 파일의 요구사항 ID가 기존과 일치하면 그 항목을 수정(이력 보존), 파일에 없는 기존 요구사항 ID는 삭제, 새 요구사항 ID(또는 빈 값)는 신규 등록됩니다.

검증 후 반영

파일을 바로 반영하지 않고, 먼저 검증(Dry-run)으로 행별 오류·경고와 신규/수정/삭제 건수를 확인한 뒤에만 반영할 수 있습니다.

경로: 요구사항관리 → 엑셀 관리 (관리자·운영자만 메뉴에 노출됩니다)

2. 엑셀 다운로드

화면 상단 다운로드 영역의 엑셀 다운로드 버튼을 누르면, 현재 프로젝트의 요구사항정의서 전체(보관 처리되지 않은 항목)가 표준 20개 컬럼 엑셀 파일로 내려받아집니다.

이 파일은 업로드 서식과 완전히 동일한 컬럼 구성입니다. 기존 데이터를 내려받아 값을 고친 뒤 그대로 다시 업로드하면 자연스럽게 수정 반영이 되는 구조입니다.

3. 동기화 방식(요구사항 ID 매칭)

업로드 시 각 행은 요구사항 ID(수기로 관리하는 코드, 화면에 표시되는 내부 ID와는 다른 값) 컬럼을 기준으로 다음과 같이 처리됩니다.

파일의 요구사항 ID처리
기존에 등록된 요구사항 ID와 일치수정 — 내부 ID(및 생성·변경 이력)를 그대로 유지한 채 내용만 갱신되고, 이력에 "엑셀 일괄 동기화" 수정 기록이 남습니다.
비어 있거나, 기존에 없던 새 값신규 등록 — 새 요구사항으로 생성되고, 이력에 "엑셀 일괄 동기화" 등록 기록이 남습니다.
기존에는 있었지만 파일에 다시 나타나지 않음삭제 — 해당 요구사항이 완전히 삭제됩니다(요구사항 ID가 비어 있던 기존 항목도 파일에서 매칭될 수 없으므로 함께 삭제 대상이 됩니다).
삭제는 되돌릴 수 없습니다
삭제되는 요구사항은 변경관리 이력을 포함해 완전히 제거됩니다. 업로드 전 엑셀 다운로드로 현재 전체 목록을 받아 파일에 모든 요구사항 ID가 빠짐없이 포함되어 있는지 확인하십시오. 일부만 담긴 파일을 올리면 나머지 요구사항이 전부 삭제됩니다.

4. 엑셀 컬럼 안내

업로드 파일은 아래 20개 컬럼을 이 순서 그대로 포함해야 합니다(다운로드한 파일을 그대로 사용하면 순서가 자동으로 맞습니다).

업무 대분류 / 업무 중분류 / 업무 소분류-자유 텍스트

구분-설정 → 공통코드 → 요구사항 구분에 등록된 값과 정확히 일치해야 합니다. 일치하지 않으면 오류로 처리됩니다.

5. 업로드·검증(Dry-run)

경로: 요구사항관리 → 엑셀 관리 → 업로드

① 파일 선택
업로드 영역에 .xlsx 파일을 끌어다 놓거나 클릭해 선택합니다. .xlsx가 아닌 파일은 선택되지 않습니다.
② 검증(Dry-run)
검증(Dry-run) 버튼을 누르면 실제로 반영하지 않고 파일 내용만 확인합니다. 결과로 행별 처리 구분(신규/수정), 오류, 주의(경고)가 표에 나타나고, 파일에 없어 삭제될 기존 요구사항 건수가 있으면 상단에 붉은 안내가 표시됩니다.
흔한 주의(경고) 메시지 — 기능분류·구분 값이 공통코드에 없을 때 등은 오류로 처리되어 반영이 막힙니다. 검증 결과 표의 "오류" 열에 표시된 행은 값을 고쳐 파일을 다시 올려야 합니다.

6. 반영

검증 결과에 오류가 0건이고 정상 행이 1건 이상이면 반영 버튼이 활성화됩니다.

① 반영 버튼 클릭
신규/수정 건수와, 삭제될 요구사항이 있다면 그 건수까지 표시하는 확인 대화상자가 뜹니다.
② 동기화 반영 확인
대화상자에서 동기화 반영을 눌러야 실제로 적용됩니다. 취소를 누르면 아무 것도 반영되지 않습니다.
③ 결과 확인
반영이 끝나면 "신규 N건 · 수정 N건 · 삭제 N건을 반영했습니다." 메시지가 나타나고, 요구사항정의서 목록에서 즉시 확인할 수 있습니다.
동시 작업 주의
반영은 프로젝트의 요구사항 전체를 대상으로 하는 작업입니다. 다른 담당자가 요구사항을 개별 화면에서 동시에 수정하고 있지 않은지 확인한 뒤 반영하십시오.

8. 문제 해결

상황확인 및 조치
기능분류·구분 값이 오류로 표시됨설정 → 공통코드에 등록된 요구사항 기능분류/구분 라벨과 파일의 값이 정확히 일치하는지 확인하십시오(공백·오탈자 포함 완전 일치).
중요도·우선순위·수용여부·확정후추가 값 오류각각 상/중/하, 검토중·수용·부분수용·미수용·보류, 예/아니요 중 정확한 값인지 확인하십시오.
등록일자 형식 오류엑셀 날짜 셀 형식이거나, 문자열이면 YYYY-MM-DD와 같이 날짜로 인식 가능한 형식이어야 합니다.
같은 요구사항 ID가 중복 오류로 표시됨파일 안에 동일한 요구사항 ID가 두 행 이상 있는 경우입니다. 한 행만 남기고 나머지를 정리하십시오.
의도치 않게 요구사항이 삭제될 것으로 표시됨파일이 전체 목록이 아니라 일부만 담고 있을 가능성이 높습니다. 엑셀 다운로드로 현재 전체 데이터를 받아 그 위에서 수정한 뒤 다시 업로드하십시오.
반영 버튼이 비활성화됨검증 결과에 오류가 1건이라도 있으면 반영할 수 없습니다. 오류 0건이 될 때까지 파일을 수정하고 다시 검증하십시오.
엑셀 관리 메뉴가 보이지 않음관리자·운영자 권한인지 확인하십시오.

9. 운영 체크리스트

업로드 전

  • □ 최신 엑셀 다운로드로 전체 목록 확보
  • □ 기존 요구사항 ID를 임의로 지우거나 바꾸지 않았는지 확인
  • □ 기능분류·구분 값이 공통코드와 일치하는지 확인
  • □ 신규 행은 요구사항 ID를 비워 두었는지 확인

반영 전

  • □ 검증(Dry-run) 오류 0건 확인
  • □ 신규/수정 건수가 예상과 일치하는지 확인
  • □ 삭제 예정 건수가 있다면 의도한 것인지 확인
  • □ 다른 담당자의 동시 수정 여부 확인
